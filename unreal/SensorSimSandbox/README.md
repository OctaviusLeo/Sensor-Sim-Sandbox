# unreal/SensorSimSandbox

UE 5.8 C++ project for Sensor Sim Sandbox. Build, run, and test instructions are in the
repository root [`README.md`](../../README.md).

- `SensorSimSandbox.uproject`, `Config/`, `Content/Maps/RoverLevel.umap`
- `Source/SensorSimSandbox/`: `Rover/`, `Sensors/` (lidar, camera, IMU, GPS), `Pipeline/`,
  `Bridge/` (Rosbridge_Client), `Coords/` (REP 103, TF), `GroundTruth/` (Run_Log),
  `Run/` (end-to-end run manager), `Tests/` (Unreal Automation)
